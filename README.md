# fe-interview-prep

Frontend interview prep assignment: five React + TypeScript (strict) features, each on its own route
and shipped as its own pull request.

## Run it

Requires Node 22 and pnpm.

```bash
pnpm install
pnpm dev          # http://localhost:5173
```

| Command | What it does |
|---|---|
| `pnpm dev` | Start the dev server |
| `pnpm test` | Run the Vitest + Testing Library suite |
| `pnpm lint` | ESLint with zero warnings allowed |
| `pnpm typecheck` | TypeScript strict type-check |
| `pnpm build` | Type-check and production build |

Stack: Vite, React 19, TypeScript (strict), React Router, Vitest, Testing Library, ESLint, Prettier.
